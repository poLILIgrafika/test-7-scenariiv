# Тест «7 сценаріїв» — Мар'яна Герасименко

Інтерактивний психологічний тест на 7 несвідомих сценаріїв, які керують життям. Одна сторінка, без бекенду, без збору персональних даних.

## Що всередині

- 7 екранів-сценаріїв по 5 тверджень кожен (чекбокси)
- питання про сферу життя, де відчувається найгостріше
- екран результату: провідний і тіньовий сценарій, бар-чарт профілю по всіх семи, шкала інтенсивності, розбір «ціни» сценарію (стосунки / гроші / реалізація), перший крок на сьогодні
- кнопка «Хочу діагностику» веде напряму в Telegram Мар'яни

## Технології

Чистий HTML/CSS/JS в одному файлі (`index.html`), без збірки й залежностей. Скоринг і вся логіка рахуються в браузері.

## Деплой

Сторінка розрахована на GitHub Pages / Vercel — досить віддати `index.html` як точку входу.
